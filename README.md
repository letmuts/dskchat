# dskchat

dskchat 是一款基于 Rust + Tauri 2 的**非官方 DeepSeek 客户端**。Windows 安装包与 Android APK 开箱即用，无需自建后端、无需自行构建：下载安装后，在设置里填入 DeepSeek API Key 即可对话。本地存储、Markdown / KaTeX / Mermaid、语音输入与朗读、历史导入导出等体验，尽量与 DeepSeek 官方 App / 网页版保持一致。

[English](README.en.md) | 简体中文

本项目是 DeepSeek API 静态聊天示例（[deepseek-ai/deepseek-chat-demo](https://github.com/deepseek-ai/deepseek-chat-demo)）的 Windows / Android 封装：前端保留在 `web/`，原生外壳在 `src-tauri/`，同一份前端代码可分别构建为纯 Web 站点与 Tauri 应用。

> 当前源码版本 **0.1.2**，以 [`src-tauri/tauri.conf.json`](src-tauri/tauri.conf.json) 的 `version` 为准；版本口径见 [版本说明](docs/version.md) 与 [配置说明](docs/配置说明.md)。

## 下载安装

下载：<https://github.com/letmuts/dskchat/releases>

Release 提供 Windows 安装包与 Android APK：

- **Windows**：下载 exe 双击运行。需要 Windows 10/11；WebView2 在 Win11 预装，Win10 多数已随 Edge / Windows Update 安装，缺失时安装包会自动下载。安装包未做代码签名，SmartScreen 可能提示风险。
- **Android**：下载 APK 安装，最低 Android 8.0（API 26）；首次安装需允许“未知来源”。仓库里的 `pnpm tauri:android:build` 目前只编译 `aarch64`，如需其他 ABI 请见 [Android 打包](docs/ANDROID.md)。
- **首次使用**：打开设置填入 DeepSeek API Key。Key 只保存在本机 WebView 的 localStorage（明文，未接系统钥匙串），发起对话时会随请求发送给配置的 API 服务，详见[数据与隐私](#数据与隐私)。

## 功能

- 多会话、自动标题、重命名与删除；编辑提问、重新生成和切换消息分支。
- 流式回答、深度思考、智能搜索、链接阅读与来源引用；支持停止生成，以及符合条件的继续生成。
- 附件上传、粘贴与拖拽，语音输入和回复朗读；移动端录音时输入框首行显示实时频谱。
- Markdown、代码高亮、KaTeX 公式与 Mermaid 图表。
- 简体中文与英文、浅色与深色主题、移动端布局、位置设置。
- 历史导入导出（ZIP），以及“删除所有对话”的本地数据清理。

## 项目结构

```text
package.json / pnpm-lock.yaml   前端依赖与脚本
rust-toolchain.toml             锁定 Rust 工具链
rspack.config.ts                前端打包配置（Web / Tauri 两个目标）
app-icon.png                    应用图标源文件，icons/ 由它生成

web/                            前端（React + TypeScript）
  app/                          应用布局、主题与视口
  components/                   聊天、设置、Markdown 等界面组件
  platform/                     原生模块槽位：契约、默认实现、构建期切换
  i18n/                         中英文文案
  services/
    api/                        API 请求、SSE 与协议类型
    chat/                       会话、消息分支、本地存储与历史导入导出
    markdown/                   Markdown 解析、代码高亮与图表
    speech/                     录音与朗读
  utils/                        通用工具

src-tauri/                      原生外壳（桌面 + Android）
  Cargo.toml / Cargo.lock       Rust 依赖与模块 feature
  src/modules/                  Rust 模块槽位，一个模块一个 Cargo feature
  vendor/tauri-plugin-opener/    内置的 opener 插件（见下方说明）
  tauri.conf.json               窗口、CSP、打包目标、安卓 minSdk
  capabilities/                 IPC 权限（默认只开 core:default）
  icons/                        各平台应用图标
  gen/                          tauri android init 生成的安卓工程（不入库）

permissions/autogenerated/      Tauri 生成的权限参考与命令清单
docs/                           Tauri、平台模块、Android、品牌与版本文档
scripts/                        Android 权限补丁与 CI 辅助脚本
.github/workflows/              CI 定义（当前文件名带 .1 后缀，需改名才生效）
```

> **为什么内置 `tauri-plugin-opener`**：crates.io 版本在 Android 构建时会把 `tauri-api` 复制进 Cargo registry 缓存目录，只读环境下报 `拒绝访问 (os error 5)`。仓库把它 vendor 到 `src-tauri/vendor/` 并用路径依赖引用，Android 才能稳定构建。

## 技术栈与版本

- **前端**：React 18 + TypeScript，rspack 2 打包；状态管理 zustand；Markdown 使用 micromark / mdast，代码高亮 Prism，公式 KaTeX，图表 Mermaid；本地存储 IndexedDB（idb），历史导入导出用 fflate 处理 ZIP。
- **桌面 / Android**：Tauri 2（Rust）。桌面使用系统 Evergreen WebView2，不随包运行时；单实例，启动失败写 `startup.log` 并弹原生错误框；程序装在非系统盘时，WebView2 数据目录兜底到同卷的 `.webview2-data/`。
- **原生模块**：只有 `system`（打开外链 / 保存文件）已实现；`secrets`、`http`、`storage`、`archive`、`search` 目前是契约或占位，已接线的模块会自动回落到 Web 实现。完整表格见[原生模块槽位](docs/PLATFORM_MODULES.md)。
- **当前锁定版本**（以 `Cargo.lock` / `pnpm-lock.yaml` 为准）：

| 组件 | 版本 |
|---|---|
| Rust 工具链 | 1.99.1（`rust-toolchain.toml` 固定） |
| `tauri` / `tauri-build` | 2.12.0 / 2.7.0 |
| `wry` / `tao` / `webview2-com` | 0.57.3 / 0.37.3 / 0.39.1 |
| `tauri-plugin-opener` / `tauri-plugin-single-instance` | 2.5.4（vendor） / 2.5.5 |
| `@tauri-apps/api` / `@tauri-apps/cli` | 2.12.5 / 2.12.6 |
| Node.js / pnpm | 22.12+ / 10 |

## 数据与隐私

API Key 和设置保存在 WebView 的 localStorage（Web 构建是浏览器 profile，桌面端是 WebView2 profile）。原生系统钥匙串槽位尚未实现，因此 Key 以明文保存。会话及附件原件保存在 IndexedDB，本地数据按浏览器用户配置和站点源（origin）隔离。发送对话、上传附件和使用语音功能时，相应内容会提交给配置的 API 服务。

桌面端（Windows）WebView2 数据目录由 [tauri.conf.json](src-tauri/tauri.conf.json) 的 `identifier` 推导，目录名即 `com.letmuts.dskchat`：

| 路径 | 内容 | 何时出现 |
|---|---|---|
| `%LOCALAPPDATA%\com.letmuts.dskchat` | WebView2 用户数据目录：`localStorage`（API Key、语言、主题等设置）、`IndexedDB`（会话与附件原件）、缓存与 cookie | 首次启动。Tauri 在创建窗口前就建好该目录，不等 WebView2 写入，所以刚建好时可能是空目录；正常跑起来后里面会出现 `EBWebView` 子目录 |
| `%LOCALAPPDATA%\com.letmuts.dskchat\startup.log` | 启动失败 / panic 记录 | 仅在启动失败时写入 |

- 数据目录名来自 `identifier`；但 `startup.log` 的路径在 [lib.rs](src-tauri/src/lib.rs) 里**硬编码**为 `com.letmuts.dskchat`，改 `identifier` 时必须同步改它，否则排错会指错目录。迁移步骤见 [docs/BRANDING.md](docs/BRANDING.md)。
- exe 与 `%LOCALAPPDATA%` 不在同一卷时，[lib.rs](src-tauri/src/lib.rs) 会把 WebView2 数据目录兜底到 exe 同卷的 `.webview2-data/`（设计说明见 [docs/TAURI.md](docs/TAURI.md)）；实际生效位置以该目录内是否出现 `EBWebView` 子目录为准。
- 退出程序后删除该目录等于清空本地设置、会话与附件缓存，下次启动会重新创建；只想清会话请用设置 → 数据管理 → 删除所有对话。
- Android 端数据在应用私有目录内（由系统沙箱隔离），不适用上表。

设置中的历史导入导出使用 ZIP（`export_format_version: 3`）。导入会在确认并校验成功后替换全部本地会话和附件；导出包含会话与本地可用的图片原件，不包含 API Key、设置或非图片附件原件。格式与保留范围见[历史导入导出](web/services/chat/history/README.md)。

设置 → 数据管理 → 删除所有对话，会在确认后清空全部本地会话、附件原件和未发送的草稿，停止正在生成的回复并回到新对话。API Key 和其他设置保留，已上传到 API 服务的文件不受影响。

## 构建与编译

| 目标 | 需要 |
|---|---|
| 通用 | Node.js 22.12+、pnpm 10 |
| Windows | Rust 1.99.1（`rust-toolchain.toml` 固定）、MSVC C++ 工具链、WebView2 |
| Linux | Rust、`libwebkit2gtk-4.1-dev`、`librsvg2-dev`、`libdbus-1-dev`、`patchelf` |
| Android | JDK 17、Android SDK 34、NDK 26、四个 Rust Android target |

### Windows

```sh
pnpm install
pnpm tauri:build
```

- 可执行文件：`src-tauri/target/release/dskchat.exe`
- 安装包：`src-tauri/target/release/bundle/nsis/*.exe`、`bundle/msi/*.msi`（[`bundle.targets`](src-tauri/tauri.conf.json) 为 `all`，Windows 上会同时尝试 NSIS 与 MSI）。
- 首次打包需要联网下载 NSIS / WiX；网络受限时会报 ``failed to bundle project: `timeout: global` ``，此时 exe 已生成，可用 `pnpm tauri build --bundles nsis` 只打 NSIS。
- 开发桌面端用 `pnpm tauri:dev`。

### Linux

```sh
sudo apt-get update
sudo apt-get install -y libwebkit2gtk-4.1-dev librsvg2-dev libdbus-1-dev patchelf
pnpm install
pnpm exec tauri build --bundles deb,rpm
```

产物在 `src-tauri/target/release/bundle/deb/` 与 `rpm/`。不指定 `--bundles` 时还会尝试 AppImage，需要额外的打包工具，建议显式指定。

### Android

```sh
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
pnpm tauri:android:init
pnpm tauri:android:build
```

`tauri:android:init` 会自动执行 `scripts/patch-android.mjs` 补 `RECORD_AUDIO` / `MODIFY_AUDIO_SETTINGS` / `INTERNET`。APK 在 `src-tauri/gen/android/app/build/outputs/apk/universal/release/app-universal-release.apk`。

`tauri:android:build` 等价于 `tauri android build --apk --target aarch64`，只编译 arm64-v8a。上架 Google Play 用 `pnpm tauri android build --aab`（不带 `--target` 时按 Tauri 默认编译目标集合）；签名与 ABI 说明见 [Android 打包](docs/ANDROID.md)。

### 纯 Web 构建

```sh
pnpm build       # 产物在 dist/，可直接部署为静态站点
```

Web 构建不会包含任何 `@tauri-apps` 代码，原生模块开关对它无效。

## 开发

| 命令 | 说明 |
|---|---|
| `pnpm install` | 安装依赖 |
| `pnpm dev` | 启动 Web 开发服务器（8090） |
| `pnpm build` | 构建静态站点到 `dist/` |
| `pnpm build:tauri` | 构建供外壳加载的前端 |
| `pnpm tauri:dev` | 桌面开发（rspack + 窗口） |
| `pnpm tauri:build` | 桌面安装包 |
| `pnpm tauri:android:init` | 生成 Android 工程 |

| `pnpm type` | TypeScript 类型检查 |
| `pnpm lint` | oxlint 检查 |
| `pnpm format` | oxfmt 格式化 |

> 目前所有 Tauri 命令仍由 pnpm 脚本转发；[`docs/version.md`](docs/version.md) 里的“改用 cargo 启动”是 0.1.3 的计划项，尚未落地。

[rspack.config.ts](rspack.config.ts) 默认使用 `https://api.deepseek.com`。可用 `createConfig({ apiOrigin, target, nativeModules, devServer })` 自定义 API 地址、构建目标与原生模块开关。

## 接口

- 聊天固定使用 `deepseek-flash`（[`web/services/chat/store.ts`](web/services/chat/store.ts)），走 Anthropic 兼容的 `/anthropic/v1/messages` 与 `/anthropic/v1/files`；语音使用 `/v1/tools/asr`、`/v1/tools/tts`。
- 请求还会带上搜索、链接阅读、标题生成与 `latest_reminder` 等扩展字段，因此配置的服务端需要支持对应能力。
- 附件格式由服务端校验决定；修改前端请求域名时，必须同步修改 [tauri.conf.json](src-tauri/tauri.conf.json) 的 `connect-src`，否则会被 CSP 静默拦截。
