# 代码发布与审查
- 此文档禁止ai agent进行任何修改，在修改前必须获得用户明确批准。

本文档旨在规定一套开发完的代码提交合并的流程，防止ai开发或人工开发出现如下问题：
- 文档与代码落后
- 从pc端或安卓端角度出发对代码进行修改时，未考虑到另外一段的情况。
- 文档英文版未更新。

## 流程如下
- h1 将修改好的代码提交至dev分支
- a2 读取dev分支代码
- a3 更新文档，其中readme文档只看待提交的代码有没有对readme文档产生影响（例如如果不是关键性改动，readme文档上面说的都对的话就不改了），其他文档根据各自分管的部分视情况做必要性更新。声明禁止修改的不更新文档。
- a4 审查代码的兼容性，看是否存在“只从pc端或安卓端角度出发对代码进行修改，未考虑到另外一段的情况。”的问题。
- a5 如果文档更新了，请更新对应的英文文档（目前只有根目录的readme.md存在此情况，其他文档不存在）
